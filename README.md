# Conversor_de_Temperatura
Conversor de Temperatura 🌡️

Projeto desenvolvido para realizar conversões de temperatura de forma simples e rápida.

O conversor permite transformar valores entre Celsius (°C), Fahrenheit (°F) e Kelvin (K), facilitando a utilização de diferentes unidades de temperatura.

🚀 Funcionalidades
Conversão entre Celsius, Fahrenheit e Kelvin.
Interface simples e fácil de utilizar.
Cálculos realizados automaticamente.
Projeto desenvolvido com foco em lógica de programação e prática de desenvolvimento.

🎯 Objetivo

Este projeto foi desenvolvido como uma forma de praticar conceitos fundamentais de programação, como funções, operações matemáticas, manipulação de valores e interação com o usuário.

📌 Sobre o projeto

Um projeto simples, mas importante para aprimorar conhecimentos em desenvolvimento e lógica de programação, servindo também como parte do meu portfólio.
